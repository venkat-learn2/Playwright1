1️⃣ What is TypeScript?
=========================
Answer:

TypeScript is a superset of JavaScript developed by Microsoft.

It adds:
========

Static typing

Interfaces

Classes

Compile-time error checking

TypeScript code is compiled into JavaScript before running in the browser or Node.js.

Example:

let name: string = "Venkat";

=============================================================================================================
2️⃣ Difference Between JavaScript and TypeScript
=====================================================
JavaScript	TypeScript
Dynamically typed	Statically typed
Errors appear at runtime	Errors appear at compile time
No interfaces	Supports interfaces
Harder to maintain large apps	Better for large applications
=============================================================================================================

3️⃣ What are Type Annotations?
==============================

Type annotations define the type of variable.

Example:

let age: number = 25;
let name: string = "John";
let isActive: boolean = true;

This helps detect errors during development.
=============================================================================================================

4️⃣ What is any type?
===========================

any means disable type checking.

Example:

let data: any = 10;
data = "hello";
data = true;

But it is not recommended because it removes TypeScript safety.
=============================================================================================================

5️⃣ What is an Interface?
===========================

Interface defines structure of an object.

Example:

interface User {
  name: string;
  age: number;
}

let user: User = {
  name: "Venkat",
  age: 25
};

Used heavily in API responses and automation frameworks.
=============================================================================================================

6️⃣ What is the difference between Interface and Type?
=======================================================

Both define object structure.

Example:

Interface
interface User {
  name: string;
}
Type
type User = {
  name: string;
};

Difference:

Interface	Type
Used for object structure	More flexible
Can be extended easily	Supports union types
=============================================================================================================

7️⃣ What is Union Type?
===========================

Union allows multiple types.

Example:

let value: string | number;

value = "hello";
value = 10;
=============================================================================================================

8️⃣ What is Optional Property?
===========================

Used when property may or may not exist.

interface User {
  name: string;
  age?: number;
}

Here age is optional.
=============================================================================================================


9️⃣ What is Type Inference?
===========================

TypeScript automatically detects type.

Example:

let name = "Venkat";

TypeScript automatically understands it is string.
=============================================================================================================


🔟 What is Enum?
===========================

Enum is used to define named constants.

Example:

enum Status {
  Pending,
  Approved,
  Rejected
}

let current = Status.Approved;
=============================================================================================================

1️⃣1️⃣ What are Generics?
===========================

Generics allow reusable components.

Example:

function identity<T>(value: T): T {
  return value;
}

identity<string>("hello");
identity<number>(10);
=============================================================================================================

1️⃣2️⃣ What is readonly?
===========================

Prevents modification.

interface User {
  readonly id: number;
}

Once set, it cannot be changed.
=============================================================================================================


1️⃣3️⃣ Difference Between null and undefined
===========================
null	undefined
intentional empty value	variable declared but not assigned

Example:

let a = null;
let b;
=============================================================================================================

1️⃣4️⃣ What is Type Assertion?
===========================

Telling TypeScript explicitly what type something is.

Example:

let value: any = "hello";

let length = (value as string).length;
=============================================================================================================

1️⃣5️⃣ What is unknown Type?
===========================

Safer alternative to any.

let data: unknown;

if (typeof data === "string") {
  console.log(data.length);
}
=============================================================================================================

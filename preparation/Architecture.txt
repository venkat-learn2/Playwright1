selenium
========
1. In selenium each and every request (action) we have make request from client and server then server return a response.
2. if u r making 100 actions it will send 100 request and and return 100 response each and every it will make a connnection establish and disconennected.
3. HTTP Protocol
4. for each and every request connnection will be terminated(that is why its takes more time)
5. http - uni directional Protocol
